PUBLICATION SUR GITHUB PAGES :
1. Décompressez l'archive.
2. Créez un repository GitHub public (par exemple heritage-bamileke).
3. Importez tous les fichiers contenus dans ce dossier à la racine du repository.
4. Dans Settings > Pages, choisissez Deploy from a branch, main, /(root), puis Save.
5. Après quelques minutes, le site sera disponible sur https://votre-pseudo.github.io/heritage-bamileke/

Les photos sont chargées depuis des URLs externes. Une connexion internet est nécessaire pour les afficher.
